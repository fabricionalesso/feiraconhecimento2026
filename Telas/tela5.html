5. Discos rígidos (HD)

Outra grande transformação aconteceu com os discos rígidos, ou HDDs. Eles utilizam discos magnéticos para armazenar dados e permitem acessar diferentes partes das informações sem precisar percorrer todo o conteúdo sequencialmente.

Um dos primeiros exemplos foi o IBM RAMAC, que ajudou a transformar a maneira como os computadores acessavam informações. Segundo a IBM, seu sistema de acesso aleatório reduziu processos que poderiam levar dias para encontrar informações para apenas segundos.

Com o passar das décadas, os HDs ficaram menores, mais rápidos e passaram a armazenar quantidades cada vez maiores de dados.
